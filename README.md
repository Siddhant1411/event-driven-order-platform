# Event-Driven Order Platform

A mid-level event-driven microservices project built using Java, Spring Boot, Kafka, and Docker.

## Planned Microservices
- Order Service
- Payment Service
- Inventory Service
- Notification Service
- API Gateway

## Tech Stack
- Java 17
- Spring Boot
- Apache Kafka
- Docker & Docker Compose
- PostgreSQL

## Goal
To build a production-style event-driven system and showcase clean architecture, messaging, and containerization.
